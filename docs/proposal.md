# 사건 정리 서비스 기획서

> 종이 더미로 쌓인 사건 자료를 한눈에 보이게 정리하고,
> **다음에 무엇을 해야 하는지** 구체적으로 알려주는 웹 서비스

| 항목 | 내용 |
|---|---|
| 대상 | 장기 미제·실종 사건 가족, 대응 방법을 모르는 피해자 |
| 형태 | 웹 서비스 (모바일 우선) |
| 수익 | B2C + B2G |
| 현재 단계 | 1번 기능 UI 목업 완료 |

---

## 1. 문제

### 이런 장면에서 시작합니다

시골 어느 집 방 한 켠에, 판결문과 수사 기록과 진정서 사본이 **박스째로 쌓여 있습니다.**
몇 년치입니다. 본인은 다 읽어봤지만, 지금 그 사건이 어디까지 왔는지, 무엇이 빠졌는지,
다음에 무엇을 해야 하는지는 아무도 정리해 주지 않았습니다.

이분들에게 필요한 건 위로도, 법률 지식도 아닙니다.
**"이 종이 더미가 지금 무슨 상태인지"**와 **"그래서 다음에 뭘 하면 되는지"** 두 가지입니다.

### 문제는 세 겹입니다

**1) 자료가 물리적으로 흩어져 있다**
종이, 캡처, 문자, 접수증이 각각 다른 곳에 있습니다. 시간 순서로 늘어놓는 것조차 하루 종일 걸립니다.
본인조차 사건 전체를 한 번에 설명하지 못합니다.

**2) 장기화되면 되돌리기 어려워진다**
시간이 지날수록 자료는 유실되고 기억은 흐려집니다. 가족은 지치고 사건은 우선순위에서 밀립니다.
제출 기한이나 이의신청 기간처럼 **지나가면 끝나는 시점**들이 조용히 지나갑니다.

**3) 다음에 무엇을 해야 할지 모른다**
이게 핵심입니다. 자료는 다 있는데 **행동을 모릅니다.**
어떤 서류를 어디에 내야 하는지, 지금 신청할 수 있는 게 있는지, 누구에게 물어야 하는지.
AI에게 물어봐도 "변호사와 상담하세요" 같은 일반론이 돌아옵니다.

---

## 2. 이 서비스가 하는 일

### 두 가지입니다

**① 한눈에 보이게 만든다**
쌓아둔 종이를 사진으로 찍어 올리면, 시간·인물·사건 단계별로 정리해 하나의 흐름으로 보여줍니다.
자료 간에 어긋나는 부분과 아직 확인되지 않은 부분을 함께 표시합니다.

**② 다음 행동을 알려준다**
정리된 사건 상태를 바탕으로, **지금 할 수 있는 가장 구체적인 행동 하나**를 제시합니다.
"변호사와 상담하세요"가 아니라, 무엇을 · 어디에 · 어떻게 · 언제까지인지까지입니다.

---

## 3. 다음 행동 강령이란 (핵심)

이 서비스의 결과물은 조언이 아니라 **실행 가능한 지시**입니다.
행동 하나는 항상 다음 네 가지를 갖춥니다.

| 구성 | 내용 |
|---|---|
| **무엇을** | 필요한 서류·자료의 이름 (이미 가진 것 / 새로 발급받아야 할 것 구분) |
| **어디에** | 담당 기관과 창구 이름 |
| **어떻게** | 방문 / 우편 / 온라인 제출 경로 |
| **언제까지** | 기한이 있으면 남은 날짜, 없으면 권장 시점 |

### 출력 예시 (형식 예시이며, 실제 절차는 검증 필요)

**사례 A — 중고거래 사기, 신고 후 진행이 멈춘 경우**

```
다음 행동
이체확인증을 발급받아 담당 수사관에게 추가 제출하세요

  무엇을     거래은행 발급 이체확인증 (예금주 정보 포함본)
             ※ 지금 가진 이체 캡처만으로는 계좌 명의가 확인되지 않습니다
  어디에     ○○경찰서 사이버수사팀 담당 수사관
  어떻게     방문 제출 또는 형사사법포털 온라인 제출
  언제까지   접수 후 3주 경과 — 이번 주 안에 권장

  왜 필요한가
  현재 자료에서 "판매자가 말한 계좌 명의"가 확인되지 않은 상태입니다.
  이 항목이 채워져야 다음 단계로 넘어갑니다.
```

**사례 B — 장기 미제 사건, 수사가 중지된 경우**

```
다음 행동
새로 확인된 사실을 정리해 재수사 요청서를 접수하세요

  무엇을     기존 사건번호 · 새로 확인된 사실 1건 이상 · 신청인 신분증
             ※ [재검토 요청서] 기능으로 문서를 자동 생성할 수 있습니다
  어디에     관할 지방검찰청 민원실
  어떻게     방문 또는 우편
  언제까지   기한 없음 — 다만 관련자 진술 확보가 가능한 시점이 지날수록 불리

  왜 필요한가
  올려주신 자료 중 2019년 목격 진술이 기존 수사 기록에 포함되어 있지 않습니다.
```

### 행동 강령은 어디서 나오는가

두 가지를 결합합니다.

1. **사건 상태** — AI가 재구성한 현재 흐름에서 "무엇이 비어 있는가"
2. **절차 지식베이스** — 사건 유형별 표준 절차·제출처·필요 서류·기한

2번은 AI가 지어내면 안 되는 영역입니다. **사람이 검증한 절차 데이터를 별도로 구축**하고,
AI는 "이 사건 상태에 해당하는 절차는 무엇인가"를 매칭하는 역할만 합니다.
사건 유형을 한 번에 넓히지 않고 하나씩 검증해 가며 늘리는 이유입니다.

## 4. 타겟

**1차 (주 타겟) — 자료는 쌓였는데 진행이 멈춘 사람**
장기 미제·실종 사건 가족, 몇 년째 진정과 재수사 요청을 반복하는 당사자.
자료가 종이 형태로 대량 존재하고, 디지털 도구에 익숙하지 않은 경우가 많습니다.

이들은 **절차를 몰라서 막힌 것이 아닙니다.** 어디에 무엇을 내는지는 이미 알고 있고,
여러 번 냈는데도 사건이 움직이지 않아 막혀 있습니다.
그래서 이들에게 필요한 건 절차 안내가 아니라 **"왜 지금까지 진행되지 않았는가"에 대한 진단**입니다.

**2차 — 사건 직후 대응 방법을 모르는 사람**
중고거래 사기, 온라인 피해 등 비교적 정형화된 사건.
자료는 적지만 초기 대응 타이밍이 결정적입니다.

> **1차 타겟으로 시작합니다.**
> 진입 장벽은 2차가 낮지만, 2차는 절차 안내 성격이 강해 범용 AI 대비 차별점이 약합니다.
> 반면 1차 타겟의 "왜 안 움직였는가"는 **자료 전체가 모여야만 답할 수 있어 대체되지 않고**,
> 지불 의사도 높습니다. 여기서 구축한 절차 지식베이스를 재사용해 2차로 확장합니다.

## 5. 기능

### 기능 1 — 사건 리서치·재구성 엔진 `UI 목업 완료`

올린 자료를 시간·인물·사건 단계별로 재구성하고, 교차 분석해 **비어 있는 곳**을 찾습니다.

- 여러 자료에 흩어진 Event·Entity·Claim을 출처와 함께 하나의 구조로 통합
- 자료 간 불일치 탐지 — 진술과 기록이 어긋나는 지점
- 공개 자료에서 확인되지 않는 정보 표시
- 추가 확인이 필요한 사항 제시 → **여기서 행동 강령이 만들어집니다**
- 전문가에게 물어볼 질문 생성

**종이 자료 입력이 1순위입니다.** 사진 여러 장을 한 번에 올리면 OCR로 날짜와 인물을 뽑아
자동으로 시간순 배열하고, 읽히지 않은 부분만 사용자에게 되묻습니다.

### 기능 2 — 나의 사건 카드 `다음 단계`

재구성 결과를 **현재 상태와 다음 행동**으로 압축한 화면. 사용자가 가장 자주 여는 곳입니다.

```
[중고거래 사기]

  ●───●───●───◐───○───○
  발생  송금  신고  접수  수사  결과
                 ▲ 지금 여기

  확보 자료 4     확인 필요 5     완료 3/5

  다음 행동
  → 이체확인증을 발급받아 담당 수사관에게 제출
    이번 주 안에 권장
```

새 자료나 대응 내용이 추가되면 상태와 타임라인이 갱신되고, AI가 다시 분석해 다음 행동을 바꿉니다.

### 기능 3 — 재검토 요청서 `이후`

정리된 사건을 **수사기관에 실제로 제출할 수 있는 문서**로 출력합니다.
기능 1에서 만든 출처 번호가 그대로 각주가 되므로, 받는 사람이 근거를 즉시 확인할 수 있습니다.

- 사건 경위 · 확보 자료 목록 · 확인 요청 사항
- 모든 주장에 출처 표기
- 용도: 재수사 요청, 진정서, 변호사 인계용 사건 파일

## 6. 접근성 — 이 서비스의 성패가 걸린 부분

1차 타겟은 **60대 이상, 스마트폰 사용이 익숙하지 않은 분들**입니다.
기능이 아무리 좋아도 여기서 막히면 아무도 쓰지 못합니다.

| 원칙 | 적용 |
|---|---|
| 입력은 사진 한 장부터 | 파일 정리·이름 변경·순서 맞추기를 요구하지 않는다. 찍어서 올리면 끝 |
| 한 화면에 하나만 묻는다 | 긴 양식 대신, 한 번에 질문 하나 |
| 결과는 큰 글씨 한 줄로 | "다음 행동"은 항상 화면에서 가장 크고 가장 위에 |
| 종이로 되돌릴 수 있게 | 정리된 사건과 다음 행동을 **인쇄 가능한 A4로 출력**. 종이가 익숙한 분들의 매체를 부정하지 않는다 |
| 대신 해주지 않는다 | 자동 제출이 아니라, 들고 갈 것을 손에 쥐여 준다 |

---

## 7. 우리가 하지 않는 것

이 서비스가 신뢰를 잃는 경로는 하나뿐입니다 — **AI가 아는 척하는 것.**

- **범인을 지목하지 않는다.** 자료로 확인되는 것과 확인되지 않는 것을 나눌 뿐입니다.
- **사건의 진실을 결론짓지 않는다.** 재구성은 해석이 아니라 배열입니다.
- **출처 없는 문장을 쓰지 않는다.** 모든 항목은 원본의 몇 번째 줄에서 왔는지 되짚을 수 있습니다.
- **법률 자문을 대신하지 않는다.** 전문가를 대체하지 않고, 전문가에게 갈 때 들고 갈 것을 만듭니다.
- **절차를 지어내지 않는다.** 행동 강령은 검증된 절차 데이터에서만 나옵니다.

## 8. 왜 범용 AI로는 안 되는가

| | 범용 AI 챗봇 | 이 서비스 |
|---|---|---|
| 시작 조건 | 사용자가 무엇을 물을지 알아야 함 | 자료를 올리기만 하면 됨 |
| 자료 처리 | 대화창에 붙여넣은 만큼만 | 종이 사진 포함 전체 자료를 하나의 흐름으로 |
| 결과 | "변호사와 상담하세요" | 무엇을·어디에·어떻게·언제까지 |
| 근거 | 어디서 나온 말인지 알 수 없음 | 모든 항목이 원본 자료로 연결 |
| 지속성 | 대화가 끝나면 사라짐 | 사건이 누적되고 상태가 갱신됨 |

## 9. 수익 모델

**B2C — 문서·보관 단위 결제**
사건 정리와 다음 행동 확인까지는 무료. **제출용 문서 출력**과 **장기 사건 보관**에서 과금합니다.
가치가 가장 분명해지는 지점에 과금선을 둡니다.
→ 장기 미제·실종 사건 가족, 수사 진행이 필요한 피해자

**B2G — 기관 라이선스**
접수된 진정·재수사 요청 자료를 구조화해 담당자의 검토 시간을 줄입니다.
민원인이 정리해서 제출하면 기관의 처리 비용 자체가 내려갑니다.
→ 경찰청, 지자체 피해자 지원 기관, 법률구조 단체

## 10. 로드맵

| 단계 | 내용 |
|---|---|
| **현재** | 기능 1 UI 설계 완료 — 자료 수집부터 확인 필요 목록까지 5개 화면 목업 |
| 다음 | **종이 자료 OCR 정확도 검증** — 박스 단위 자료가 첫날부터 들어오므로 최우선 과제. 반려·기각 통지서를 우선 처리 대상으로 |
| 그다음 | 재구성 엔진 기술 검증 (추출 정확도·불일치 탐지) + 시도 이력(무엇을 언제 내고 어떤 답을 받았는가) 모델 설계 |
| 파일럿 | **수사중지 사건 한 유형** — 재개 요건 지식베이스를 이 유형만 완성하고, 법률 전문가 검수를 파이프라인에 넣어 실제 사건 소수로 깊게 검증 |
| 확장 | 사건 카드 → 재검토 요청서 → 2차 타겟(정형 사건)으로 확대 |
| 이후 | 기관 대상 검증 (B2G) |

## 11. 아직 답하지 못한 것

- **절차 지식베이스를 어떻게 구축·검증할 것인가.** 이 서비스의 실제 난이도는 AI가 아니라 여기 있습니다. 법률 전문가 검수 체계가 필요합니다.
- **재구성 엔진의 기술 구성이 미정입니다.** 추출 정확도가 신뢰도를 그대로 결정하므로 가장 먼저 검증해야 합니다.
- **"공개 자료"의 범위.** 언론 보도·판례·공공 데이터 중 어디까지 수집하고 어떻게 최신성을 유지할 것인가.
- **가격과 과금 단위.** 문서 1건인지, 사건 1건인지, 기간 구독인지에 따라 제품 구조가 달라집니다.
- **민감 자료 보관 정책.** 피해 사실이 담긴 자료를 다루므로 암호화·보관 기간·삭제 권한을 초기에 설계해야 합니다.
