# 규칙별 시험 사건

규칙표 13줄(0~12번)을 **규칙마다 실제 서류로 발화시켜 보는** 시험이다. 사건 하나가 규칙 하나를 겨냥한다.
인물 · 사건 · 서류는 전부 지어낸 것이다. 문구는 실제 서식(수사결과 통지서 · 접수증 · 이체확인증 등)의 항목 이름을 따랐다.

- 각 폴더는 `research-engine` 이 받는 입력(OCR 이 서류를 읽은 모양)이고, 카드는 손으로 쓰지 않는다.
- 사건은 `만들기.py` 가 만든다. 사건을 고치려면 그 파일을 고치고 다시 돌린다.
- `case.json` 의 `expect` 가 겨냥한 규칙, `why` 가 그 사건을 만든 이유다.
- `out.json` 은 research-engine 출력이다. 사본이 `action-engine/tests/fixtures/rules/` 에 있고
  `tests/test_rules_by_case.py` 가 규칙마다 발화를 확인한다. 엔진을 고쳐 출력이 바뀌면 사건을 다시 돌리고
  사본도 바꾼다(아래 '돌리는 법').

## 돌리는 법

```bash
py 시험자료/규칙별/만들기.py
cd research-engine
uv run research-engine run ../시험자료/규칙별/<폴더>/case.json --out ../시험자료/규칙별/<폴더>/out.json
cd ../action-engine
uv run pytest tests/test_rules_by_case.py -rxX
```

## 처음 돌렸을 때 닿지 못한 규칙과 고친 것

처음에는 9 / 13 이었다. 0 · 10 · 11 · 12번은 어떤 서류를 넣어도 닿지 않았고, 원인은 사건이 아니라 엔진에 있었다
(원인 코드를 빼고 규칙표만 다시 돌리면 기대한 규칙이 발화하는 것으로 확인했다).

1. **0번(재판 단계) — 검찰의 기소 결정을 읽지 못했다.** 처분결과 통지서의 `구공판(공소제기)` 가
   research-engine 의 결정 문구(`extract/claims.py` 의 `DECISION_TYPE`)에 없어 단계 미확정(ST-UNKNOWN)이 되고
   4번(단계확인)이 발화했다. → `구공판 · 구약식 · 공소제기 · 기소` 를 결정 문구에 넣었다
   (`기소` 는 불기소 · 기소중지 · 기소유예 · 기소의견이 아닐 때만).
2. **10 · 11 · 12번 — INF-043(전문 분석 미실시)이 모든 사건에서 켜졌다.** action-engine 은 자료함에 감정서가
   없으면 INF-043 을 켰는데, research-engine 에는 감정서 문서 종류가 없어 감정서를 올려도 `unknown` 이었다.
   그래서 9번(근거보완)이 늘 먼저 발화했다.
   → research-engine 에 감정서(`forensic`, 기록 자료) 종류를 더했고, action-engine 은 감정이 수사의 핵심인
   사건 유형(지금은 실종 사건)에서만 감정서가 없는 것을 INF-043 으로 본다. 사기 사건처럼 감정이 필요 없는 사건에
   켜면 9번 뒤의 규칙에 영영 닿지 않는다.
3. **11번 — 수사 중인 사건은 아직 없는 결정을 빠진 항목으로 셌다.** '결정 내용'이 필수 항목이라 수사 중인
   사건에서도 빠진 것(INF-041)으로 잡혀 9번에 가려졌다. → 아직 결과 단계에 이르지 않은 사건의 '결정 내용 ·
   결정 일자 없음'은 근거 미비로 옮기지 않는다.

9번은 이제 INF-043 이 아니라 이 사건의 INF-041(피해 날짜가 고소장에만 있음)로 발화한다.

## 사건을 만들며 알게 된 것 (고쳐서 넣었다)

- **새 정보(6번)는 앞선 '사건 발생' 기록이 있어야 잡힌다.** 고소장에 `투자금 3천만원을 보냈습니다` 라고만
  적으면 송금으로 읽혀 발생 단계 사건이 없고, 결정 뒤에 나온 목격 진술을 새 정보로 잡지 못했다.
  `편취당했습니다` 로 적으면 잡힌다. 실제 고소장의 표현이 다양하므로 기능 1이 송금도 발생의 시작으로
  볼지 검토가 필요하다.
- **사건 발생 시점은 기록 자료에 있어야 확인된다.** 고소장(본인 말)에만 있으면 필수 항목이 확인되지 않아
  INF-041 로 9번이 먼저 발화한다. 10 · 11 · 12번 사건은 접수증에 `발생일시` 를 적어 넣었다.
